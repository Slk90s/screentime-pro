# ScreenTime Pro

> 跨平台电脑应用使用时长追踪工具（macOS / Windows / Linux），对标 iOS「屏幕使用时间」。
> 数据 **100% 本地存储、零上传**，隐私优先。

## ✨ 功能特性

### 📊 使用统计与可视化

- **实时前台追踪**：后台持续采样当前使用的应用、窗口标题与使用时长（顶部实时指示「正在记录：XXX」）。
- **设备总览**：累计时长 / 日均 / App 数量 / 切换次数 / 最长单 App / 最常使用，一屏看清。
- **按天柱状图**：iOS 风格的每日分类堆叠柱，点选某一天即可下钻当天详情。
- **日历月视图**：月总时长 / 活跃天数 / 日均 / 最常使用 / 最忙的一天。
- **24 小时 × 分类堆叠**：看清一天里各类应用（社交 / 效率 / 开发 / 娱乐…）的时间分布。
- **App 使用时长排行**：当天哪些应用最耗时，按分类着色。
- **趋势对比**：本周 / 本月 vs 上周 / 上月，并含**去年同期同比**；含分类占比与 Top 应用。
- **空闲检测**：超过设定阈值无操作视为「离开」，不计入有效使用时长（阈值可调）。

### 🎯 分类规则引擎

- 按「**字段**（进程名 / 窗口标题 / 可执行路径 / 包名 / 展示名）× **匹配方式**（包含 / 相等 / 前缀 / 后缀 / 正则）+ 匹配值」自动归类。
- 规则支持增删改、优先级排序与启用开关，可一键「**按规则重算历史**」。
- 新软件自动入库（默认「其他」）；内置 60+ 本地字典 + Wikipedia 兜底归类 + LRU 缓存。

### 🖥 系统状态栏（三端统一）

- **悬浮指标条**：桌面常驻、可自由拖拽的透明指标条，1Hz 实时显示 **CPU / 内存 / 网速 / 磁盘**占用；全屏自动隐藏、位置跨启动记忆、宽度自适应内容。
- **托盘常驻**：关闭窗口不退出，托盘恒为品牌图标；右键菜单提供「启用状态栏」总开关 / 显示主窗口 / 退出，左键单击唤出主窗口。
- **设置页「状态栏」卡片**：总开关 + CPU / 内存 / 网速 / 磁盘 子项，与托盘右键菜单**双向同步**。
- macOS / Windows / Linux **行为完全一致**（系统指标统一由悬浮指标条呈现）。

### 📸 屏幕截图

- **全局快捷键唤起**：默认 `Ctrl / Cmd + Shift + A`，随时全屏选区截图。设置页**点一下按钮、直接按下组合键**即可改键（不用记格式），被系统或其他软件占用时会即时提示并回滚，刻意避开与系统「截图工具」冲突的 `Win + Shift + S`。
- **仿 QQ 浮动工具栏**：选区完成后就地弹出工具条——矩形 / 箭头 / 画笔 / **马赛克（打码，三档强度）** / 文字 / **取字**、撤销、圆角与投影、全屏、保存 / 复制 / 取消 / 确认；选区角落显示实时尺寸药丸，8 个手柄可缩放、选区内可整体拖动。
- **就地标注，不用重截**：抓到的屏幕画面会**冻结成一张图**，加文字、画框箭头、给敏感信息**打码**都在同一张截图上完成，确认前可随时撤销。
- **取字（本地离线 OCR）**：点「取字」即对当前选区识别文字，结果面板可一键**复制文字**；Windows 走系统内置 `Windows.Media.Ocr`，**不联网、不上传**（macOS / Linux 待接入系统 Vision / Tesseract）。
- **默认进剪贴板**：截图确认后 **直接复制到系统剪贴板**，随手 `Ctrl / Cmd + V` 即可粘贴；保存为可选开关。
- **所见即所得**：圆角与投影在工具栏里实时预览，导出由本地 canvas 合成 → 屏幕上看到的就是导出的那张图。
- **本地历史（FIFO）**：可选自动保存到本地历史目录，超出上限的旧图**自动移入系统回收站**；设置页可缩略图回看、在文件夹中定位、逐条删除。
- **托盘入口**：系统托盘右键菜单新增「截图」项，快捷键失效时亦可触发。

### 💾 多设备与数据

- **多设备合并**：不同电脑的数据按「时间 + 应用 + 设备」去重后合并查看，首页可切换设备。
- **数据导出 / 导入**：JSON 全量备份与跨设备合并。
- **本地自动备份**：定时自动备份数据库 + 可设保留份数 + 立即备份；被替换的旧备份移入系统回收站。
- **数据维护**：可设数据保留天数、按设备清理旧数据、一键清空。
- **检查更新**：直接读取 GitHub Releases 检查新版本。
- **诊断**：可打开日志目录、导出日志，便于反馈问题。

### 🌐 界面与体验

- **数据 100% 本地**：SQLite 本地存储，零上传，隐私优先。
- **多语言**：简体中文 / English，界面实时切换、多窗口同步。
- **深色模式**：跟随系统深浅色自动切换。
- **开机自启**：首次运行默认开启，可随时关闭。
- **权限与依赖引导**：macOS 辅助功能权限缺失时弹出引导横幅；Windows 检测 WebView2 运行时缺失并给出下载入口。

### 🐼 桌宠（🧪 Beta 测试版功能）

- 透明置顶、可自由拖拽的 **3D 潮玩桌宠**：随当前前台应用自动切换表情状态；点击触发 跳跃 / 弹压 / 抖动 / 射蛛丝 等互动；随机弹出气泡对话；眼神漂移 + 眨眼、嘴部张合等微表情。
- **多皮肤**：3D 潮玩熊猫（Pop Mart 风格）/ 蜘蛛侠，设置页或右键桌宠即可切换。
- **表情编辑器**：按状态自定义 emoji 表情并实时预览。
- **喂食系统**：竹叶 / 苹果 / 糖果，饱食度随喂食与时间衰减变化，含每日上限。
- **不挡路（v0.8.0）**：按**像素级 alpha** 判定，鼠标落在熊猫透明区域时自动「穿透」给下方窗口；落在实体像素上才可交互，拖拽更跟手。
- **前台全屏自动隐藏（v0.8.0）**：检测到前台应用进入全屏（macOS 已支持**真·全屏识别**，可区分「最大化」）时自动隐藏，退出全屏自动恢复。
- ⚠️ 该功能仍处于 Beta 测试阶段（可能不稳定），可在「设置」页随时开关。

### 💾 文件命名规则

每个发布版本的文件名都带 **版本号 + 平台架构**，便于区分：

| 平台 | 文件名格式 | 说明 |
|------|-----------|------|
| macOS (Apple Silicon) | `ScreenTime.Pro_{ver}_aarch64.dmg`（另附 `ScreenTime.Pro_aarch64.app.tar.gz`） | 拖入「应用程序」即可，需授予「辅助功能」权限 |
| Windows (x64) | `ScreenTime.Pro_{ver}_x64-setup.exe` | 双击运行（NSIS 安装包），需系统已装 **WebView2 运行时** |
| Linux (x64) | `ScreenTime.Pro_{ver}_amd64.AppImage` / `ScreenTime.Pro_{ver}_amd64.deb` / `ScreenTime.Pro-{ver}-1.x86_64.rpm` | 由 CI 在 Linux 环境构建 |
